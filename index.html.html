Import CSV

Import your own candidate lines, historical picks, or model output. No API key required.

Recognized columns: market, book, event, selection, line, odds, model_probability, stake, date, status, notes. Model probability may be a decimal (0.57) or percentage (57). Imported rows are stored as candidates/pending records, not automatically marked as bets.
